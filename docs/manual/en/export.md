# Export

This export produces lists for viewing and further processing; it cannot be imported again. To back up KMM or move it, use the [backup](backup.md).

In the movie and TV show lists, **Export** downloads the current list. It exports exactly what the selected [filter](filters.md) together with the search shows, including the entries on further pages.

## Formats

| Format | Content |
|---|---|
| **HTML list with posters (ZIP)** | A standalone list with a search field and scaled-down posters. Unzip the ZIP and open the HTML file in your browser. The result is suitable for sharing. |
| **CSV for Excel** | With commas and decimal points (in the German interface: semicolons and decimal commas); umlauts are displayed correctly. “yes” and “no” appear as text. |
| **JSON** | For further processing in other programs. Lists are real arrays. |

## Columns

**Movies:** title, original title, year, genres, runtime, certification, rating, user rating, watched, resolution, video codec, audio tracks, subtitles, movie set, tags, IMDb, TMDB, file, added.

**TV shows:** title, original title, year, status, genres, network, seasons, episodes, unwatched episodes, rating, user rating, tags, TVDB, TMDB, IMDb, folder, added.

The **File** and **Folder** columns contain your paths. Keep this in mind if you pass an export on.
