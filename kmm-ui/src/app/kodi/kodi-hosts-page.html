Kodi

KMM aktualisiert Kodi nach Änderungen an Filmen über die JSON-RPC-Schnittstelle. In Kodi dafür unter Einstellungen → Dienste → Steuerung „Steuerung über HTTP erlauben“ aktivieren und Port, Benutzer und Passwort hier eintragen. Über die Pfad-Zuordnung findet KMM die Filme unter Kodis eigenen Pfaden, z. B. smb://nas/filme/.
